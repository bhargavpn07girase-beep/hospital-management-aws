EC2 IAM Role Authentication Strategy

When deploying on Amazon EC2:

  1. Create an IAM Role with a policy granting s3:PutObject and s3:ListBucket for {{ s3_bucket }}.
  2. Attach this IAM Role directly to the EC2 Instance Profile.
  3. Boto3 will automatically fetch temporary security tokens from the EC2 Instance Metadata Service (IMDS).
Zero Secret Leakage: No access keys or secret keys reside in Git or on the server filesystem.
